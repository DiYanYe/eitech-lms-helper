东方理工 LMS 助手 — 使用说明
================================

一、运行环境
- Windows 10 / 11
- Microsoft Edge 浏览器（系统自带，无需额外安装）
- 无需安装 Python 或任何依赖

二、安装 / 启动
1. 将整个压缩包解压到任意【可写】目录（桌面、文档均可）。
   注意：不要解压到 C:\Program Files 等受保护目录，否则程序无法保存数据。
2. 双击「东方理工LMS助手.exe」启动。

三、首次使用
1. 在登录页点击「登录」，会弹出 Edge 窗口，请在其中完成学校统一身份认证（CAS）登录。
2. 登录成功后回到主界面，点击「管理课程」勾选需要关注的课程。
3. 在「资料下载」页选中课程即可浏览/勾选文件并下载；已下载过的文件会自动跳过；
   下载进行中再发起的新任务会自动排队，当前任务完成后接续（点「取消全部」则一并取消）。
4. 下载的文件默认保存在程序目录旁的 downloads\ 文件夹（可在界面中更改目录）。

四、常见问题
- 杀毒软件报毒？本程序未做数字签名，属 PyInstaller 打包的常见误报，请添加信任/放行。
- 提示「未找到 Microsoft Edge」？请安装或更新系统 Edge 后重试。
- 登录状态失效？程序会自动回到登录页，重新登录即可。
- 数据安全：登录凭证（Cookie）以 Windows 加密存储在本机，仅当前电脑、当前用户可解密，
  不会随程序拷贝到其他电脑；课程数据与下载记录仅存本机。

五、卸载
直接删除程序文件夹即可（可选：同时删除其旁的 data\ 与 downloads\ 文件夹）。
