# 东方理工 LMS 助手

面向宁波东方理工大学学生的超星平台辅助工具（Windows 桌面应用）：**批量下载课程"资料"区文件**、**汇总课程作业**，仅此而已。

- 登录用学校统一身份认证（CAS），程序不接触你的账号密码
- 只做只读操作：不答题、不刷时长、不绕过教师下载权限

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 批量下载资料 | 目录树勾选（支持全选、文件夹联动，并显示各资料的平台上传时间），按网页目录结构落盘，已下载的自动跳过；老师更新过的同名文件按上传时间自动覆盖更新 |
| 下载管理 | 实时进度、统计、随时取消；下载中再发起新任务会自动排队接续；关掉窗口可最小化到托盘后台继续 |
| 作业列表 | 按状态分组（未交置顶），双击直接在浏览器打开作业页 |
| 登录复用 | 登录一次后本地加密缓存，下次启动自动登录；"重新登录"可强制换账号 |

## 快速上手（免安装，解压即用）

1. **下载**：到 [Releases](https://github.com/DiYanYe/eitech-lms-helper/releases) 下载 `eitech-lms-helper-v1.0.zip`
2. **解压**：放到任意**可写**目录（桌面、D 盘都行；**不要放 Program Files**）
3. **登录**：双击 `东方理工LMS助手.exe`，点「登录」会弹出 Edge 或 Chrome 窗口（自动检测），完成学校 CAS 登录后自动回到软件
4. **选课程**：左上角课程选择器 → 「管理课程」→ 勾选你要关注的课程（只勾选的课程才会拉取数据）
5. **下载**：在「资料下载」页选课程 → 勾选文件/文件夹 → 点开始下载。文件保存在 `下载目录/<课程名>/<文件夹>/`，与网页上的目录结构一致
6. **看作业**：左侧切到「作业列表」，双击条目在浏览器中打开作业详情

下载目录默认在程序文件夹的 `downloads/` 下，可在「资料下载」页自行更改（会记住）。

## 常见问题

**Q：下次打开还要登录吗？**
不用。启动会自动用本地缓存的登录状态。想换账号点「重新登录」，会强制弹出浏览器重新走一遍 CAS。

**Q：换电脑还能用吗？**
登录状态绑定的本机（Windows 加密），拷贝过去也无效。新电脑上重新登录一次即可，下载的文件随便拷。

**Q：有的文件下载不了？**
教师未开放下载的文件（网页上也无法下载）本工具同样不会强行获取，这是刻意设计。

**Q：重复下载会下两份吗？**
不会。已下载的文件自动跳过（按记录 + 本地文件双重判断），可以放心反复点。确需强制重下：退出程序后删除程序文件夹里的 `data` 目录（注意：会同时清除登录状态，需重新登录）。

**Q：老师更新了课件，本地还是旧版怎么办？**
不会漏。每次下载前会用平台列表里的上传时间与本地基线（下载记录 / 本地文件时间）比对：平台较新时直接覆盖旧文件，下载管理页显示「已更新」；本地文件比平台新（自己改过）则不会覆盖。
下载完成后本地文件时间会被写成平台的上传时间，方便对照。

**Q：杀毒软件报毒？**
本程序未做代码签名，打包方式容易被误报。在本机将其加入信任/白名单即可，也可自行从源码运行（见下）。

**Q：第一次登录弹出的浏览器很久没反应？**
浏览器首次以新配置启动会偏慢，等几十秒；之后会快很多。

## 环境要求

- Windows 10 / 11 + Microsoft Edge 或 Google Chrome（其一即可，自动检测，Edge 优先）
- 使用 Release 包无需安装 Python；仅"从源码运行"需要 Python 3.12

## 面向开发者

```powershell
git clone https://github.com/DiYanYe/eitech-lms-helper.git
cd eitech-lms-helper
pip install -r requirements.txt        # 运行依赖（DrissionPage / httpx / bs4 / lxml / PySide6）
python -m app.ui.main                  # 启动 GUI（真实登录 + 真实下载）

# 构建免安装便携包
pip install -r requirements-dev.txt    # 构建期依赖（pyinstaller / pillow）
python scripts\make_ico.py             # 仅 logo 变更时需要
pyinstaller 东方理工LMS助手.spec --noconfirm   # 产物：dist/东方理工LMS助手/
```

- 登录链路：DrissionPage 驱动真实 Edge/Chrome（自动检测）完成手动 CAS 登录，Cookie 经 Windows DPAPI 加密落盘（`data/cookies.bin`，仅本机当前用户可解密），请求链路走 httpx 并带随机限速
- 平台接口的逆向结论见 [`docs/接口实测文档.md`](docs/接口实测文档.md)（改接口适配层前必读）；项目约定与踩坑速查见 [`AGENTS.md`](AGENTS.md)
