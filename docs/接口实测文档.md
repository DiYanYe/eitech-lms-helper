## 课程列表

```
POST https://mooc2-ans.chaoxing.com/mooc2-ans/visit/courselistdata
Content-Type: application/x-www-form-urlencoded
Referer: https://mooc2-ans.chaoxing.com/mooc2-ans/visit/interaction

courseType=1&courseFolderId=0&query=&superstarClass=0
```

- 返回 HTML；`div.course` 每门课一块，hidden inputs：`input.clazzId` / `input.courseId` / `input.curPersonId`（即 cpi）
- 课程名无稳定选择器，从 div 文本按 `班级：` 上一行切分
- 同一接口兼做会话健康检查：响应含 `passport2.chaoxing.com` / `统一身份认证` 即登录态失效

## 学习页与三个 enc

入口：`GET https://mooc1.chaoxing.com/visit/stucoursemiddle?courseid=&clazzid=&cpi=&ismooc2=1&v=2`（跟随重定向）。

| enc | 位置 | 用途 |
| --- | --- | --- |
| `stuenc` | 学习页最终 URL 的 `enc=` 参数 | 资料区根页面、作业列表 URL |
| `coursedata-enc` | 资料行 `onclick="toOpen(...)"` 第 10 个参数 | 资料区文件夹遍历 XHR |
| `work-enc` | 学习页隐藏域 `<input id="workEnc" value="...">` | 作业列表 URL |

**三个 enc 互相独立，均现取现用，不强缓存。**

## 资料区（stu-datalist）

根页面（完整 HTML）：

```
GET https://mooc2-ans.chaoxing.com/mooc2-ans/coursedata/stu-datalist
    ?courseid={courseId}&clazzid={clazzId}&cpi={cpi}&ut=s&stuenc={stuenc}
```

文件夹遍历（同一端点 XHR，地址栏 URL 不变）：

```
&dataName={URL编码文件夹名}&dataId={folderId}&type=1&parent=&flag=0
&enc={coursedata-enc}&microTopicId=0&t={毫秒时间戳}&isAjax=isAjax
```

行结构 `ul.dataBody_td`：

- 属性：`type`（`afolder`/`pdf`/`pptx`/`docx`/`mp4`/`tch-courseware`…）、`id`（=dataId）、`dataname`（文件名）、`objectid`、`loadurl`、`url`、`isdown`（0/1）
- 文件大小：`li.dataBody_size_stu` 文本（约数，如 `14KB`）
- `onclick="toOpen('name','type',dataId,'loadurl','objectId','url',flag,source,'clazzid','{coursedata-enc}','video_type','t','')"`

#### 上传时间字段（2026-09-28 探针实证，`scripts/probe_file_time.py`）

- 行内时间：**`li.dataBody_time_stu`**，文本形如 `09-22  22:42`（**月-日 时:分，无年份**；日与时间之间是两个空格）；
  上传者：`li.dataBody_creater_stu`；文件与文件夹行都有时间
- **无年份**：实现按“当前年”推定，若落到未来（超 1 天缓冲）回退一年（跨年边界）；解析实现见
  `app/core/api/materials._parse_time_text / _extract_row_time`（容错多候选：行 data-* 属性 → 含 time/date 的 li → 行全文兜底，均失败返回 None）
- 行 `ul` 上的 `t` 属性与 toOpen **第 12 个参数**是毫秒级**请求时间戳**（同一层的所有行相同、每次刷新变化），
  **不是**文件上传时间，不要拿来当基线
- 解析陷阱（已踩）：日与时间之间的分隔若写成 `\s*日?` 再跟 `[\sT]+`，贪婪 `\s*` 会吞掉空格使时:分丢失（时间被解析成当天 0 点）

要点：

- **逐级懒加载**：每个文件夹一次请求，`dataId` 指定当前层
- `isdown=0` 表示教师未开放下载（平台不渲染下载按钮）——**必须尊重，不强行获取**
- `tch-courseware`（教师课件）无 dataId：**产品决策不下载**，仅列出不遍历

#### 分页（2026-09-26 实证）

- **pageSize = 30**。注意："当前页共 N 个"是**每页条数**，不是该层总数（早期误判为总数的教训）
- 层 HTML 内嵌隐藏域 **`<input id="totalPages" value="N">` 直接声明该层总页数**，用它精确翻页
- 翻页参数矩阵实证（样本：Python程序设计基础 Exercise_codes 层，totalPages=2、第 2 页 28 条新数据）：**`&pages=N` 有效**（N 从 2 起）；`page`/`pageNum`/`currentPage`/`pageIndex` 均返回原第 1 页（无效）
- 实现：`materials._fetch_paged` 按 totalPages 逐页取；totalPages 缺失时满页（30 条）兜底持续翻页；达 `MAX_PAGES` 仍未终止则告警（不静默漏文件）
- 实测样本：Exercise_codes 层 30 + 28 = 58 个文件，两页抓全
- 已知满页层（可能多页）：Python程序设计基础 Exercise_codes（×2 学期）、高等数学Ⅱ根目录——接入 GUI 后首次同步会自动补齐第 2 页

## 下载（downloadData → cldisk）

```
GET https://mooc1.chaoxing.com/coursedata/downloadData
    ?dataId={dataId}&classId={clazzId}&cpi={cpi}&courseId={courseId}&ut=s
Referer: https://mooc2-ans.chaoxing.com/mooc2-ans/coursedata/stu-datalist?...
（不跟随重定向）
```

- 302 → `https://d0.cldisk.com/download/{objectId}?at_={ms}&ak_={签名}&ad_={签名}&fn={文件名}`
- **签名直链必须带 `Referer: https://mooc1.chaoxing.com/` 请求**，否则 403（实测矩阵结论：A 裸请求 403 / B 带 Referer 成功 / C 带 Set-Cookie 同 B）
- 注意存储域已是 `d0.cldisk.com`（旧资料里的 `ananas.chaoxing.com` 直链写法已失效）
- 元数据接口 `mooc1.chaoxing.com/ananas/status/{objectId}?flag=normal` 返回"无权限"，已失效；名称/类型/大小直接取行 DOM

## 作业（work/list）

```
GET https://mooc1.chaoxing.com/mooc2/work/list
    ?courseId={courseId}&classId={clazzId}&cpi={cpi}&ut=s
    &t={毫秒时间戳}&stuenc={stuenc}&enc={work-enc}
```

条目结构：`li[data=work/task 详情URL]`，内含：

- 标题：`p.overHidden2`
- 状态：`p.status`（实测枚举：`未交` / `待批阅`，其余以平台显示为准）
- 时间：`div.time`（原文如"剩余124小时44分钟"，为相对时间；绝对截止时间在详情页）
- `data` 属性的 work/task URL 可直接用于浏览器打开详情

## 行为约定（风控安全）

- 请求间随机延迟 1~3 s；下载顺序执行，文件间随机延迟
- 偶发瞬时 `SSL UNEXPECTED_EOF`：传输层错误退避重试（3 次）
- 命中 412/403/429 或登录页跳转：立即停止，不自动硬闯
- 只读操作，不碰答题/学习行为接口

## 未决点

- 文件大小仅约数文本（跳过判断用 5%/2KB 容差），精确大小待取（可从下载响应 Content-Length 获得）
